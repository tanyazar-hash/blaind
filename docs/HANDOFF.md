# Передача упрощённого сайта «БЛАИНД»

Обновлено 12.11.2026 по новой структуре заказчика. Чёрно-золотая палитра,
исходная фишка, файлы фотографий и данные Supabase сохранены. Публичные правила сокращены.

## Структура

| Адрес | Содержимое |
| --- | --- |
| `/` | Краткая презентация клуба, месячный финал для 18 лучших, фишка в отдельном блоке и три перехода |
| `/arena/` | Сразу рейтинг: поиск, сортировка и выделение первых 18 официальных мест |
| `/tournaments/` | Только актуальные турниры, даты, описания, афиши и запись в официальный Telegram |
| `/rental/` | Две карточки без фотографий и подписей: стол с подсветкой — 700 ₽; классический — 500 ₽ с человека; кнопки в Telegram |
| `/legal/` | Краткие правила клуба: без денежных ставок, депозит только на напитки и закуски; отдельная страница персональных данных |
| `/admin/` | Защищённое управление игроками и турнирами; в статической сборке переход к backend Vercel |

Навигация едина: Главная, Рейтинг, Турниры, Аренда столов, Связаться.
Старый `/arena/#tournaments` переводит на страницу турниров. Каталоги имеют
собственные index.html, поэтому доступны напрямую и после reload на статическом
хостинге, в том числе под `/blaind/`.

## Интерфейс и производительность

Главная содержит два раздела. Нет длинной череды декоративных глав, текстовых
reveal-анимаций, вращения по курсору или перемещения фишки при скролле. Фишка
рендерится в неподвижной позе, имеет отдельное место на мобильном экране и не
перекрывает текст. Непрерывный RAF отсутствует; resize и fallback сохранены.
Короткое появление фишки отключается через prefers-reduced-motion.

Главная и аренда не загружают CSS таблицы/турниров. Используются локальные
WOFF2, готовые LOD и AVIF/WebP. Сложная старая хореография удалена; оптимизированные
модели и их лицензии сохранены. Исторические и новые замеры — `docs/PERFORMANCE.md`.

Первые 18 мест определяются по исходному рейтингу до поиска/визуальной сортировки.
Проверка использует 21 тестового игрока: 19-е место не становится «финалистом»
при фильтрации. Результаты, игроки, фотографии и правила сортировки не удалялись.

## Проверки

Node.js 22.12+ (22.x), `npm ci`, `npm run build`, `npm test`.

- `npm run test:browser`: вход/выход, редактирование, изображения, сессия и синхронное
  появление данных на отдельных страницах рейтинга и турниров. Только локальные fixtures.
- `node tests/site-browser.cjs`: новые разделы, все документы, шесть пунктов меню,
  цены и контакты, 320–1440px, граница 18 мест, отсутствие наложения фишки.
- `node arena/tests/browser.cjs`: фильтры, сортировка, live, последняя хорошая копия
  при сбое сети, повторы, пустые списки, безопасные заголовки и изображения.
- `npm run test:accessibility`: 20 состояний публичных страниц и редакторов на
  desktop/mobile, axe WCAG A/AA, 2.1/2.2 AA и best practices.
- `npm run test:polish`: клавиатура, фокус, краткие правила, WebGL-fallback,
  ошибки/восстановление админки и загрузка афиши с задержкой более 20 секунд.
- `node tests/chip-motion-browser.cjs`: настоящая GLB, оба LOD, неподвижность при
  скролле, отсутствие новых RAF, resize и освобождение потерянного контекста.
- `node tests/entrance-browser.cjs`: немедленно читаемый текст, история и отсутствие
  анимаций появления, навигация/информация без JavaScript.
- `node tests/legal-browser.cjs`: документы, внутренние ссылки, печать и no-JS.
- `npm run test:performance`: 10 размеров и холодная загрузка CPU ×4 / 1,28 Мбит/с.
- `node tests/hosting-browser.cjs`: готовая сборка на простом файловом сервере;
  повторяется с `SITE_BASE_PATH=/blaind/ STATIC_HOSTING=1` после такой же сборки.

GitHub Actions выполняет unit, polish, accessibility, статический smoke-test,
публикует Pages и отдельно проверяет настоящие Pages и Vercel без записи в базу.
На Vercel необходим публичный доступ до Supabase-входа: при Vercel SSO тест
сообщает о Deployment Protection, а не выдаёт такой вход за работу приложения.

## Сведения, которые не выдумывались

Для 700 ₽ не добавлены «за час», «за человека» или длительность. Бронирование —
переход в существующий `https://t.me/asushedulebot`; на сайте нет приёма оплаты.
Владелец подтверждает длительность/состав аренды, регламент месяца и финала,
порядок розыгрышей и обращения сертификатов. Сертификаты не объявлены деньгами
или гарантированным денежным выигрышем. Основные условия опубликованы на `/legal/`. Прежние адреса документов перенаправляются на соответствующие разделы. Отдельная галерея удалена; исходные фотографии сохранены.

Отсутствие денежных ставок и название «спортивный покер» сами по себе не дают
юридической гарантии: фактическую организацию платежей и призов подтверждает
владелец. Реквизиты исполнителя и оператора данных по-прежнему не предоставлены.
См. `docs/LEGAL_REVIEW.md`. Пароли владельца в тестах production не использовались.
Физические iPhone/Android и Safari не заменяются эмуляцией Chromium; это остаётся
ограничением доступной среды.
