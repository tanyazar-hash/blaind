# Общая система публичных страниц

`header.html` и `footer.html` — единственный источник разметки для главной, ARENA и «Атмосферы». `scripts/site-components.mjs` подставляет активную страницу в маркеры `site:header` / `site:footer` при `npm run build`. Получившийся HTML хранится в Git: шапка работает сразу, без ожидания JS/запросов и без JavaScript. При изменении шаблона включайте все три обновлённых HTML в коммит.

`site.css` подключается после индивидуальных стилей. Здесь размеры шапки, подвала, первых экранов, единые локальные шрифты, ссылки и анимации. `--site-header-height` учитывается в `--site-hero-height`, а верхний/нижний отступы задаются общими переменными. На главной мобильный первый экран резервирует место под настоящую 3D-фишку перед текстом; итоговая высота совпадает с остальными страницами.

`site.js`: одно мобильное меню, появление текста на 18px за 760ms без задержек, поддержка reduced motion, аккордеоны главной. Галерея «Атмосферы», рейтинг, серверная авторизация и 3D-хореография остаются в своих модулях. Раскрытие аккордеона отправляет `site:layout`, чтобы координаты глав основной 3D-сцены пересчитались после изменения высоты страницы.

События используют нативные details/summary: работают без JS, доступны с клавиатуры. Шапка/подвал тоже видны без JS. Зерно по-прежнему ниже фотографий, текстов и чистой 3D-сцены.

Проверки: `npm test`, `npm run test:browser`, `node tests/site-browser.cjs` (для браузерных проверок нужны Playwright и Chromium). Регрессия отдельных страниц — `arena/tests/browser.cjs` и `atmosphere/tests/browser.cjs`. Общий тест проверяет одинаковую геометрию/разметку, активную навигацию, мобильное меню, кириллицу, отсутствие горизонтального переполнения, падение/позицию фишки и аккордеоны.

Первые экраны используют отдельный общий эффект `site-hero-reveal`: появление снизу на 26px с мягким размытием 6px за 950ms. Подпись, заголовок и описание идут с одинаковым шагом 90ms на всех трёх страницах; прочие разделы сохраняют прежнее появление. Reduced motion полностью отключает смещение, размытие и задержки. Без JavaScript текст сразу виден.

Правовые документы находятся в `legal/`. При сборке всем HTML-документам этой директории подставляются общие шапка и подвал; `shared/legal-links.html` добавляется также в отдельный подвал `aces.html`. Юридические файлы включены в production `public/`. Обновляйте сами документы и шаблон ссылок, затем выполняйте `npm run build` и коммитьте обновлённые публичные HTML. `npm test` включает проверку ссылок, наличия документов в сборке и идемпотентности генерации; перед ним нужна сборка. `node tests/legal-browser.cjs` проверяет production-файлы, мобильное меню, доступность без JS и печать. Факты, правовые ограничения и список действий владельца: `docs/LEGAL_REVIEW.md`. Неподтверждённые реквизиты и ограничения проверки нельзя убирать без фактического заполнения / сверки.
