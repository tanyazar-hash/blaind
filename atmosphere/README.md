# Фотографии клуба

Отдельная страница `/atmosphere/` и её просмотрщик удалены по просьбе заказчика.
Исходные `/atm1.jpg`–`/atm7.jpg` и подготовленные изображения в `images/` сохранены.
Три фотографии используются на странице «О нас» с responsive srcset и lazy loading.
На странице аренды фотографии временно скрыты; исходные файлы не удалены.

После замены оригиналов копии можно подготовить командой
`python3 atmosphere/prepare-images.py` (нужен Pillow). Сборка использует готовые файлы.
