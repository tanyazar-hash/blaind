# Атмосфера Блаинд

Статическая страница `/atmosphere/`, отдельные HTML/CSS/JS. Использует общие цвета, компоненты шапки/кнопок/подвала, логотип и существующие локальные шрифты. Ссылка «Атмосфера» в обеих навигациях главной ведёт сюда. Подключение страницы к сборке — в `scripts/build.mjs`; отдельный rewrite не нужен для каталога с `index.html`.

Исходные фотографии: `/atm1.jpg`–`/atm7.jpg` в корне репозитория. Их содержимое и EXIF не изменяются. Готовые WebP-копии в `images/` имеют ширины 480, 960 или исходную ширину (без увеличения). Галерея использует `srcset`, `sizes`, размеры для предотвращения скачков вёрстки и lazy loading после первого кадра. Просмотрщик загружает полный WebP выбранного кадра и предварительно следующий, кроме режима экономии трафика / 2G. Без JavaScript ссылки открывают исходный JPEG.

После замены оригиналов копии можно пересоздать командой `python3 atmosphere/prepare-images.py` (нужен Pillow). Добавьте подготовленные WebP в Git: Vercel использует готовые файлы и не требует Python.

Семь кадров выводятся в асимметричной сетке, на телефонах — в одной колонке со смещениями. Параллакс ограничен 8 px, работает только на видимых кадрах при точном указателе, обновляется через requestAnimationFrame по событиям прокрутки. Анимации отключаются для prefers-reduced-motion. Зерно находится под фотографиями.

Просмотрщик: нативный modal dialog, стрелки / клавиатура / свайп, циклический переход, Esc, закрытие по фону, удержание и возврат фокуса, блокировка фонового скролла. При ошибке загрузки есть ссылка на оригинал. JavaScript страницы не обращается к API и базе данных.

Проверка production-сборки:

```sh
npm run build
python3 -m http.server 8030 --directory public
node atmosphere/tests/browser.cjs
```

Нужны Playwright и Chromium `/usr/bin/chromium`. При необходимости задайте `ATM_BASE_URL`. Проверяются 7 изображений, ширины 320–1440 px, пропорции, модальный просмотр, клавиатура, свайп, фокус, отсутствие переполнения, reduced motion, отсутствие JavaScript, ошибки изображений и обе ссылки с главной. Скриншоты — `/tmp/blaind-atmosphere`.
