# Блаинд ARENA

Статическая страница /arena, независимая от 3D-сцен главной и страницы тузов. Использует существующие шрифты, палитру и фон. На главной добавлена только ссылка ARENA в обычное и мобильное меню.

## Локальный запуск и проверки

Из корня репозитория:

~~~sh
python3 -m http.server 8010 --directory .
node --test arena/tests/*.test.mjs
~~~

Локальный адрес — /arena/ (Python перенаправляет /arena в каталог). На Vercel точный путь /arena обслуживается адресным rewrite из vercel.json. Остальные страницы и файлы не перенаправляются. У проекта нет пакетной установки или этапа сборки.

## Данные

- data/players.json — дата обновления, демонстрационный флаг и игроки.
- data/tournaments.json — дата обновления, часовой пояс, демонстрационный флаг и упорядоченные турниры.
- types.d.ts — отдельные контракты Player, RankedPlayer, Tournament, ArenaDataSource.
- data-source.js — HTTP-загрузка и проверка контракта; не зависит от интерфейса.
- ranking.js — расчёт мест, поиск и сортировка; не изменяет исходные данные.
- arena.js — интерфейс, анимации, раскрытие деталей и просмотр изображений.

ID должны быть уникальными и постоянными. Место рассчитывается по очкам, затем по победам, затем по никнейму и ID. Поиск и сортировка отображения не меняют официальное место. Места не хранятся в JSON.

Даты — ISO 8601 с явным часовым поясом, например 2026-11-13T19:00:00+07:00. Время турниров отображается в timeZone из ответа, независимо от часового пояса устройства. Рейтинг показывает дату в часовом поясе клуба — Новосибирск.

isDemo: true оставляет подписи демонстрационных данных. При подключении реальных результатов API может вернуть isDemo: false.

## Изображения турниров

Каждый турнир хранит собственный imageUrl. Сейчас это файлы WebP в arena/images, подготовленные из существующих 3D-моделей клуба.

~~~json
{
  "imageUrl": "./images/golden-night.webp",
  "imageAlt": "Чёрно-золотая фишка Блаинд",
  "imageFit": "cover",
  "imageFocus": { "x": 50, "y": 50 },
  "imageStorageKey": null
}
~~~

Пути к локальным файлам задаются относительно /arena/. Поддерживаются и абсолютные HTTPS-адреса CDN. imageFit: "contain" подходит для вертикальных афиш, которые нужно показывать целиком; "cover" заполняет карточку без искажения пропорций. imageFocus управляет точкой кадрирования. В увеличенном просмотре изображение всегда отображается целиком.

- Добавить: положить изображение в проект и указать его путь.
- Заменить: изменить imageUrl и при необходимости подпись/фокус.
- Удалить: установить imageUrl: null (или пустую строку). Появится фирменная заглушка.
- Если файл не загружается, также отображается заглушка; кнопка увеличения недоступна.

Не добавляйте секретные ключи хранилища в публичные JSON-файлы. imageStorageKey — необязательный идентификатор объекта для будущего администратора, а не учётные данные.

## Подключение будущего API и админ-панели

В data-source.js можно заменить два URL в createArenaDataSource на публичные GET-эндпоинты. Они возвращают те же структуры, что и JSON. Функции getPlayers(signal) и getTournaments(signal) остаются неизменными; таблицу и карточки переписывать не требуется.

Будущая админ-панель управляет этими записями через отдельный защищённый API. При загрузке файла с компьютера её backend проверяет тип и размер, загружает объект в облачное хранилище и сохраняет публичный/CDN URL в imageUrl, при необходимости — идентификатор в imageStorageKey. Для замены и удаления админ-панель обновляет те же поля. Изменение displayOrder меняет порядок карточек.

Сейчас нет админ-интерфейса, пользовательской загрузки файлов, базы данных, сервера записи, статусов турниров или архивов. Публичная страница только читает данные.

## Шрифты

Для ARENA локально поставляются те же Manrope и Playfair Display, что на главной. WOFF-файлы — полная упаковка официальных TTF из google/fonts, без изменения глифов. Лицензии SIL OFL находятся в fonts. Внешний шрифтовой CDN для этой страницы не требуется.

## Браузерная проверка

При запущенном локальном сервере и доступном Playwright:

~~~sh
node arena/tests/browser.cjs
~~~

Используются Chromium и Playwright из облачной среды. При необходимости задайте CHROMIUM_PATH и ARENA_BASE_URL. Скриншоты сохраняются в /tmp/blaind-arena; путь можно изменить переменной ARENA_SCREENSHOTS.

Проверяются поиск, все сортировки, сохранение официальных мест, часовой пояс, увеличение и раскрытие карточек, клавиатурный фокус, ширины 320–1440 px, вертикальные и отсутствующие изображения, повтор запроса после ошибки, пустые коллекции и обе ссылки из меню главной.
